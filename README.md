# BorneoGIS Navigator

Field mapping app for Android built with Flutter.

Developed by [Lamri](https://lamri.vercel.app) — GIS Analyst & WebGIS Developer.

## Features

- Real-time GPS tracking with UTM coordinate display
- Interactive map canvas with pan & zoom
- Pin placement via GPS or manual coordinate input (Lat/Lon & UTM)
- Multi-radius circle overlay
- Track recording with export to GPX/KML
- Import KML/GPX files as overlay
- Export pins to GPX, KML, or GeoJSON
- Compass widget
